# Finance demo source and review record

Prepared 2026-10-12. Thirty original introductory questions; ten per audience. Difficulty is inferred from the concepts, not calibrated against official examination papers. No official exam questions, curriculum text, screenshots, or provider question banks are redistributed. Reference links do not imply endorsement or permission to reproduce the reference material.

## Review performed

- Original stems, distractors, and explanations reviewed against the concepts in the cited references. No verbatim reference prose is used.
- Deterministic tests independently recompute compound/present values, holding-period and weighted returns, rolling averages, expected credit loss, recovery complement, probability-weighted loss, and the one-standard-deviation interval.
- Every pack has ten distinct stems, one correct option per question, one mark per correct answer, and zero negative marks. Correct-answer positions are varied using a stable shuffle.
- Both JavaScript validation and the Python generator validator cover the packs. Browser checks cover loading, feedback, source links, navigation, saved history, and offline embedding.
- Conceptual review and numerical assertions are agent checks; there has been no independent human subject-matter review. These demos do not establish exam readiness, mastery, or suitability as investment advice.
